# Vision Pro checkpoint: 0.1.0 (36)

This publication snapshot preserves the runtime source of development commit
`88e7df25ba2828e40dab0fce5d6482ec0cd4397b`, without publishing superseded contract-review history.

The operator tested build 36, including mode changes. Pen tip/buttons still
required an additional reconnect after a mode change; one smaller-to-larger
change succeeded. This remains an open defect. Automatic readiness and clean
teardown logs do not prove working pen tip/buttons.

Window resizing and raw mouse handling were previously live accepted. Build 36
removes the transient Use mouse in desktop control and re-enables desktop mouse
input on entry/return. The latest test does not establish every mouse regression
as resolved. Audio works; loudness, sync and interruption recovery retain their
field qualification limits. Recurring playback stutter remains open.
