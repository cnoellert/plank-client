# PLANK Apple native pilot design context

## Register

product

## Scope

This context covers the Apple native development pilots, especially iPad typing
controls. It does not change the shipping platform/support matrix in README.md.

## Users

Artists using remote creative workstations, including Autodesk Flame, with pen,
mouse and keyboard. They need accurate input and readable controls while the
remote canvas remains the primary working surface.

## Product Purpose

Provide dependable native remote playback and input with clear session controls.
Input must remain immediate; cosmetic changes must preserve accepted pen, mouse,
keyboard and reconnect behavior.

## Brand Personality

Native, precise, unobtrusive. The user's named references are Apple's iPad,
iPhone and Vision input interfaces and Apple's Human Interface Guidelines.

## Anti-references

The user rejected the oversized 24-point monospaced typing strip. Avoid large
bespoke input chrome, compose-and-Send interruptions and controls that conceal
the remote canvas without providing useful working feedback.

## Design Principles

- Keep remote work central; local controls support the current task.
- Use native Apple components and semantic typography for familiar behavior.
- Make recent typing readable while sending input live.
- Keep observed preview state distinct from remote document state.
- Preserve accepted input behavior while refining presentation.

## Accessibility & Inclusion

Use Dynamic Type, semantic colors, accessible control labels and native keyboard
shortcut presentation. Preserve hardware keyboard, finger, pointer and Pencil
paths. Do not claim an accessibility qualification without device evidence.
